# presidio2

Русский форк Presidio Analyzer для маскирования персональных данных и секретов перед отправкой сообщений в LLM. Анализатор возвращает позиции находок в исходном тексте. Интеграция с LiteLLM использует их для замены и восстановления значений в пределах одного запроса.

Сборка `2.2.366+ru.mask1` включает русские распознаватели и правила Gitleaks. Поиск email проверяет участки вокруг символа `@`, словарь форм имён использует общие префиксы, а Gitleaks вычисляет координаты находок по индексу строк. [Устройство ядра и методика проверки](RU-MASK.md)

## Сборка

Из корня репозитория выполните

```sh
cd presidio-analyzer
uv build --wheel
```

Готовый wheel появится в каталоге `presidio-analyzer/dist/`. Для совместимости с портом пакет устанавливается под именем `presidio-analyzer` и импортируется как `presidio_analyzer`.
