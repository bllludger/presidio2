# presidio2 — ядро маскирования для LiteLLM

Этот форк обслуживает один русский профиль. Порт передаёт текстовый блок и ожидает упорядоченные диапазоны символов для замены. Блоки могут содержать русский текст, исходный код и секреты. Политика исключений, перекрытия диапазонов и контекст влияют на результат. Восстановление исходных значений выполняет LiteLLM в пределах одного запроса.

## Что вошло в первую сборку

Основа репозитория — тег Presidio `2.2.366`. Пакет анализатора восстановлен из wheel работающего RU-профиля `2.2.366-1`, SHA-256 `420d7512625401e1a8750a846dd350d2e9887c261f85c153e661adeee034df83`. Номер сборки форка — `2.2.366+ru.mask1`.

- Правило email находит очередной обязательный символ `@` и выделяет участок до ближайших пробела, табуляции или перевода строки с обеих сторон. Штатное регулярное выражение работает на оригинальном буфере и возвращает исходные координаты. Несколько адресов в одном участке проверяются вместе. Бюджет времени общий для всех участков. Пользовательские выражения и нестандартные флаги проходят полную проверку.
- При запуске словарь форм имён компилируется в выражение с общими префиксами. В одной ветке более длинная форма проверяется первой.
- Gitleaks строит индекс строк после первого кандидата, использует двоичный поиск для координат и создаёт таблицу позиций UTF-8 после первой принятой находки в тексте с не-ASCII-символами.

## Архитектура следующего этапа

**За единицу работы принимаем новый текстовый блок.** Один запрос чата может породить несколько проверок. Путь блока проходит через локальный кеш, затем через настроенный Redis. После промаха выполняется фиксированный RU-профиль. Базовая единица для планирования мощности — суммарные CPU-миллисекунды анализа на запрос чата.

**Выбор правил компилируется при запуске воркера.** Для правила можно описать обязательный литерал, допустимые границы кандидата и необходимость в контексте. Уже существующий автомат Ахо — Корасик отбирает часть правил по ключевым словам. Поиск email показывает следующий шаг — сохранить позиции кандидатов и сократить участок точной проверки. Правила с контекстом за границей участка, неизвестными флагами или без доказанного маркера продолжают работать на всём блоке. Проверка качества включает точное совпадение диапазонов, Unicode, ложные срабатывания и ошибки при неполном сканировании. Такой отбор используют и другие поисковые движки. [GitHub Secret Scanning](https://docs.github.com/en/code-security/reference/secret-security/custom-patterns) · [Исследование Hyperscan](https://www.usenix.org/conference/nsdi19/presentation/wang-xiang) · [Устройство Zoekt](https://github.com/sourcegraph/zoekt/blob/main/doc/design.md)

**Работа под нагрузкой.** Прежде чем менять число воркеров, разделить в метриках ожидание свободного анализатора, время анализа, ожидание модели и её повторы. Порт уже ограничивает одновременные запросы. Если длинные блоки задерживают короткие, испытать две очереди с общей ограниченной ёмкостью, резервом для коротких и гарантированной долей для длинных. При исчерпании бюджета возвращать контролируемую ошибку до передачи текста модели. Выбирать порог по измеренной стоимости обработки. [Google SRE о перегрузке](https://sre.google/sre-book/handling-overload/) · [Envoy об управлении параллелизмом](https://github.com/envoyproxy/envoy/blob/main/docs/root/configuration/http/http_filters/adaptive_concurrency_filter.rst)

**Проверка мощности.** Подать одинаковый профиль нагрузки на 1, 2, 5 и 10 реплик. Отдельно измерить новые блоки, повторяющиеся истории и смешанный поток. На каждой ступени сопоставить корректные запросы в секунду, CPU-секунды, долю попаданий каждого кеша, p95/p99 ожидания и количество отказов. Сначала использовать детерминированный локальный ответ модели, затем повторить с настоящим бэкендом. Эти два прогона позволяют найти компонент, который ограничивает сквозной RPS.

## Сборка

Из каталога `presidio-analyzer/` выполнить `uv build --wheel`. В порте версию выбирает `profile/runtime.lock.txt`. Для попарного сравнения двух wheel из корня соседнего проекта `litellm-presidio-port/` выполнить команду

```sh
.presidio-venv/bin/python ../presidio2/presidio-analyzer/benchmarks/compare_ru_port.py \
    profile/wheels/presidio_analyzer-2.2.366-1-py3-none-any.whl \
    profile/wheels/presidio_analyzer-2.2.366+ru.mask1-py3-none-any.whl
```
